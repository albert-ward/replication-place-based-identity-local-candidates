You are a research assistant coding open-ended survey responses for an academic study. Your task is to classify each response according to a well-established typology from the place attachment literature.

## Background

In a survey experiment, participants were randomly assigned to a treatment or control condition. Treatment participants read the following prompt:

"People belong to different types of groups. One of the most important and essential of these groups is the neighborhood you belong to. Each neighborhood is different. Now we'd like to know what you think. What do you think is the most important reason people feel like they belong to your neighborhood and want to live there?"

You are coding ONLY the treatment responses. Each response is a participant's answer to the question above.

## Coding scheme

You will classify each response according to the place identity–place dependence distinction (Williams & Roggenbuck, 1989; Williams & Vaske, 2003).

**Place identity (PI)** refers to an emotional and symbolic bond grounded in social relationships and group memberships. Content coded as PI includes references to:

- People, neighbours, community, social relationships
- Knowing others and being known ("everyone knows everyone," "neighbours wave hello")
- Mutual help, looking out for each other, trust between residents
- Family or friends living nearby
- Shared culture, values, or traditions among residents
- Feeling at home among the people in the area
- A sense of belonging rooted in social ties
- Biographical rootedness — personal or family history in the area ("I grew up here," "my family has been here for generations," "I've lived here my whole life"). This is identity content because it expresses continuity of membership in a place-based group, not a functional evaluation of the area.
- Diversity or character of the people ("it's a diverse community," "people from all walks of life")

**Place dependence (PD)** refers to a functional bond reflecting the place's capacity to meet practical needs. Content coded as PD includes references to:

- Safety, low crime, security
- Schools, educational quality
- Amenities: shops, restaurants, grocery stores, gyms, libraries
- Convenience, proximity to work, commute, transport links
- Affordability, property values, cost of living, investment value
- Physical qualities valued for functional reasons: quiet streets, cleanliness, well-maintained properties
- Parks, green space, or outdoor areas described as amenities ("there's a great park nearby") rather than as settings for social interaction
- Infrastructure, services, utilities
- Climate or weather as a reason for living there
- Housing quality or size

## Classification rules

For each response, assign ONE of three codes:

1. **PI** — The response is predominantly about people, social relationships, community, or biographical rootedness. Any PD content is minor or incidental.

2. **PD** — The response is predominantly about functional qualities, amenities, safety, convenience, or practical benefits. Any PI content is minor or incidental.

3. **MX** — The response contains substantial content of both types, and neither clearly dominates. Use this code sparingly — most responses will have a discernible primary focus.

## Decision procedure

For each response:

1. Read the full response.
2. Identify each distinct claim or reason the participant gives.
3. Tag each claim as PI or PD using the definitions above.
4. Count the number of PI claims and PD claims.
5. If all or nearly all claims are PI, code PI. If all or nearly all are PD, code PD. If both are substantially present (roughly 40/60 or closer), code MX.
6. In borderline cases, ask: "Is this person fundamentally talking about the people or about the features of the place?" Code accordingly.

To do this, create a new column in the CSV called llm_code

## Edge cases

- "It's a safe, friendly neighbourhood" — "safe" is PD, "friendly" is PI. If the response elaborates on friendliness, code PI. If it elaborates on safety, code PD. If neither is elaborated, code MX.
- "I've lived here 20 years and love the schools" — biographical rootedness (PI) plus schools (PD). Code based on which the response dwells on.
- "Great location near the park where I walk my dog and chat with neighbours" — park-as-amenity is PD, but chatting with neighbours is PI. The social use of the space tips it toward PI.
- "Affordable housing and my family lives nearby" — affordability is PD, family nearby is PI. Code MX unless one clearly dominates.
- "It's quiet" — code PD. Quietness is a functional quality of the environment.
- "People mind their own business" — code PI. This is about the social norms of the community, even though it describes an absence of interaction.
- "I grew up here" or "my parents lived here" with no further elaboration — code PI. Biographical rootedness is identity content.
- "Good location" or "convenient" with no further elaboration — code PD.
- Religious or cultural community ("my church is here," "there's a strong Latino community") — code PI. This is about social group membership.
- "It's beautiful" or references to scenery, nature, views — code PD. Aesthetic appreciation of the physical environment is place dependence.
- Off-topic, incoherent, or single-word responses — code as UNUSABLE.
- Safety produced by neighbours ("neighbours keep an eye out," "we watch each other's homes") is PI. Safety as a property of the area ("low crime," "safe streets") is PD.
- "Quiet" describing how residents behave ("we don't disturb each other," "people keep to themselves") is PI. "Quiet" describing the environment ("quiet streets," "peaceful area") is PD.
- "Close" meaning close to each other is PI. "Close" meaning close to amenities, roads or work is PD.
- Descriptions of who lives there (age mix, families, diversity, class, multicultural) are PI, because they describe the social character of the place.
- Valuing privacy, space or distance from neighbours ("acreage," "no HOA," "you see nature, not your neighbour's house") is PD.
- Negative or critical responses, which say people live there despite the area or for lack of alternatives ("it's the cheapest, there's nothing here"), are coded on content like any other response. In a second new column called negative, enter 1 for these responses and 0 for all others.

Process each response independently. Do not let previous responses influence your coding of the current one.
